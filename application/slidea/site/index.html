01 / TEMPLATE LEARNING

PPTX 模板学习能力

给 Slidea 一份你现有的品牌 PPT，它能把参考稿转换为一组 SVG 素材，并由 Agent 直接阅读 SVG 源码，提炼出跨页的设计语法——配色与字体规则、圆角与描边语言、文本容器用法、图片与留白的节奏，形成一份 Style Pack。

  • 按页面类型 / 密度 / 结构自动匹配参考页（style_reference_id），封面、目录、过渡页、致谢页各归其位
  • 生成后自动还原参考稿的背景、母版、Logo、页眉页脚与页码格式
  • 样式与内容严格隔离：参考 PPTX 只提供视觉风格，绝不混入原文内容
  • 内置浅色通用、深色通用、红色政治、蓝色学术、幼小科普、中文艺术、英文艺术 7 套模板，随主题自动选择

02 / BUILT-IN DEEP RESEARCH

内置 Deep Research 深度研究

宽泛的主题不需要你先去查资料。Slidea 内置递归式研究引擎：把"写一份深度报告"拆解为任务树，逐节点检索证据、局部写作、评审缺口并收敛，最终产出结构化研究报告，直接供大纲阶段消费。

  • 任务树分解：先生成章节主干，再对重点章节渐进细化，算力花在刀刃上
  • 章节级局部上下文（Local RAG）：每章只读与自己相关的证据，避免上下文污染与内容重复
  • 规划—评审—执行收敛循环：不信任第一版提纲，主动发现缺口并修正
  • 三档研究模式：skip（已有材料）/ simple（联网快搜）/ deep（20–30 分钟深度洞察）

03 / INTERACTIVE WORKFLOW

Workflow + 交互修改：效率与灵活性兼得

研究、规划、大纲与渲染被拆成独立阶段，中间产物全部落盘缓存——质量更稳定，也让你随时介入：生成前它会主动向你确认受众与目标，生成后你可以不重跑流水线，直接逐页修改。

  • 分阶段执行 + 并发渲染：章节与内容页 worker 扇出并行生成（fan-out / fan-in）再聚合导出，等待时间大幅缩短；支持断点续跑（--continue）与单阶段重放
  • 关键信息缺失时主动中断提问（input_required），回答后同会话无缝继续（--resume）
  • 页面级修补：patch 渲染只重做缺失或指定页面，不再整份重跑
  • Phase 3 交互修改：直接在 SVG 源文件上改文案、换图片、调布局，甚至把某页重绘为架构图 / 流程图 / 时序图，改完统一导出

写作思路

大纲生成

逐页渲染

导出 PPTX

1

把安装指令发给你的 Agent

Agent 会自动获取说明并完成 Slidea Skill 的安装。

请直接获取并遵循这里的说明安装 slidea skill： https://raw.gitcode.com/openeuler/capsule/raw/master/application/slidea/skill/slidea/INSTALL.md

配置模型（.env）

最小可用配置只需一个 DEFAULT_LLM，OpenAI 兼容 API 即可。
