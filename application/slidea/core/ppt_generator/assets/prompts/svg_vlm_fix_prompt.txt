# 修复目标
根据 VLM 审阅问题修复严重视觉缺陷，重点处理：
- 文字遮挡、裁切、溢出画布
- 元素重叠、层级错乱、主体缺失
- 图片比例明显错误、图片过大或过小
- 页面大面积空白、内容密度失衡

# 必须遵守
- 只返回一个完整 standalone SVG，使用 ```svg 代码块包裹。
- 保持 width="1280" height="720" viewBox="0 0 1280 720"。
- 不要使用 foreignObject、style 标签、class、script、animation、mask、filter 或外部 CSS。
- 所有样式写在元素属性里。
- 保留原页面的主题、关键信息、语言和已有图片路径。
- 只做必要的视觉修复，不要重写成另一套无关设计。

# 内容页模板保护要求
- 如果当前 SVG 包含内容页模板结构（常见 id：background、slide-background、header、page-title-text、top-accent-bar、bottom-accent-bar、template-*、main-content-frame、content-frame-*），这些都属于受保护区域。
- 严禁更改标题部分的空间位置、字号、字重、颜色、字体、层级和装饰；不得移动、缩放、删除或重绘 header / page-title-text / top-accent-bar / bottom-accent-bar / background / main-content-frame / content-frame-* 等模板固定元素。
