# 修复目标
根据 VLM 审阅问题，仅修复动态正文中的严重视觉缺陷，重点处理：
- 文字遮挡、裁切、溢出画布
- 动态元素重叠、层级错乱、主体缺失
- 动态图片比例明显错误、图片过大或过小
- 正文区域大面积空白、内容密度失衡

# 固定外壳边界
- 截图中的背景、母版、版式、标题、标题背景、页眉、页脚、页码、Logo 和固定装饰由代码管理。
- 当前 SVG 源码已主动移除这些固定外壳节点；不要补画、复制或重新设计它们。
- 只修改当前 SVG 中已经存在的动态正文组，可以调整其坐标、尺寸、字号和层级来解决审阅问题。
- 不得创建 background、master-content、layout-content、header、footer、page-number、page-title、title-shell 等固定结构。
- 不得引用 `style-reference-only/` 或 `images/style-pack/` 下的图片。
- 返回后代码会自动重新套用原固定外壳。

# 必须遵守
- 只返回一个完整 standalone SVG，使用 ```svg 代码块包裹。
- 保持 width="1280" height="720" viewBox="0 0 1280 720"。
- 不要使用 foreignObject、style 标签、class、script、animation、mask、filter 或外部 CSS。
- 所有样式写在元素属性里。
- 保留原动态内容的主题、关键信息、语言和可用图片路径。
- 只做必要的视觉修复，不要重写成另一套无关设计。
